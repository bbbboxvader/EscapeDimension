Escape Dimension — 실행 안내

1. 게임의 실행 진입점은 main.py입니다.
2. 실행.bat를 두 번 클릭하거나 게임 폴더에서 python main.py를 실행합니다.
3. Enter로 시작하고 F1으로 조작 안내를 확인합니다.

2: 좌우 이동·낙하 / 3: WASD 자유 이동 / 4: 시간 정지·과거 위치
마우스: 조준 / 왼쪽 클릭: 발사 / R: 장전
탄창 6발 / 시작 예비탄 36발 / 합계 최대 42발입니다.
가득 차면 보급품은 소비하지 않고, 부족한 탄약만 최대치까지 보충합니다.
2D에서는 좌우만 바라보고 수평으로 발사합니다. 3D/4D는 8방향을 바라봅니다.
걷기·장전·사망 모션이 있으며 사망 동작이 끝난 뒤 Enter로 재도전합니다.
E: 상자 집기 / Q: 던지기
4D에서 휠·방향키로 과거 위치를 고르고 Enter로 이동합니다.
모든 적을 처치한 뒤 Enter로 다음 방에 갑니다.
사망하면 Enter로 재도전합니다. 40세 이상이면 처음부터 시작합니다.
Esc: 일시정지 / M: 소리 / 창 닫기: 종료

현재는 다섯 개 방이 연결된 기능 프로토타입입니다.
Python 소스와 상세 규칙은 README.md, 검증 결과는 verification 폴더에 있습니다.
소스와 levels.json을 수정하면 main.py를 다시 실행할 때 바로 반영됩니다.
Python 3.14.3과 전용 .venv 환경으로 실행을 확인했습니다.
pico2d, PySDL2, SDL DLL을 설치했으며 설치 파일은 .runtime/wheels에 있습니다.
환경 복구 명령: python tools/setup_runtime.py
선택 사항인 EXE 재빌드에만 PyInstaller가 필요합니다.

처음에는 3을 눌러 자유 이동으로 상자 뒤를 우회해 보세요.
3D에서 상자를 적보다 화면 위에 배치한 뒤 2를 누르면 낙하 공격이 가능합니다.
