## 01. 게임 개요와 기본 실행 진입점

Escape Dimension은 Python과 pico2d로 구현한 방 단위 액션 슈팅 게임이다. 모든 표시는 2D이며, 2D·3D·4D라는 이름은 이동·중력·시간 규칙의 구분이다.

게임의 기본 진입점은 `main.py`다. 프로젝트 폴더에서 `python main.py`로 실행하거나 `실행.bat`를 사용한다. 관련 안내는 [README](../README.md)에 있다.
