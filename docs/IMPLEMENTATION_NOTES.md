# Escape Dimension 구현 참고 문서

작성일: 2026-11-14

현재 구현을 35개 주제로 정리한 문서입니다. 각 항목은 실제 코드의 동작과 확인 위치를 설명합니다.
기존 15개 개발 커밋을 유지하고 이 문서의 항목을 순서대로 추가했습니다.

## 01. 게임 개요와 기본 실행 진입점

Escape Dimension은 Python과 pico2d로 구현한 방 단위 액션 슈팅 게임이다. 모든 표시는 2D이며, 2D·3D·4D라는 이름은 이동·중력·시간 규칙의 구분이다.

게임의 기본 진입점은 `main.py`다. 프로젝트 폴더에서 `python main.py`로 실행하거나 `실행.bat`를 사용한다. 관련 안내는 [README](../README.md)에 있다.

## 02. 프로젝트 전용 실행 환경

실행 라이브러리는 프로젝트의 `.venv`에 설치한다. `main.py`를 일반 Python으로 실행하면 준비된 프로젝트 Python을 다시 사용하도록 연결되어 있다.

환경 복구는 `python tools/setup_runtime.py`로 진행한다. 다운로드한 wheel이 `.runtime/wheels`에 있으면 오프라인 설치를 우선한다. 필요한 버전은 `requirements.txt`에 명시되어 있다.

## 03. 파일별 책임과 수정 위치

`core.py`는 그래픽에 의존하지 않는 규칙과 상태, `main.py`는 입력·화면·효과음, `visuals.py`는 방향·프레임·상체 변형 계산을 담당한다. `navigation.py`는 적의 우회 경로를 계산한다.

방 배치는 `levels.json`, 이미지는 `assets`, 검사는 `tests`에 있다. 소스 실행에서는 파일 수정 후 다시 실행해 결과를 확인한다.

## 04. 방 데이터와 콘텐츠 배치

`levels.json`의 `rooms` 배열은 방 이름, 안내, 시작 위치, 적 종류와 위치, 상자, 구조물, 탄약, 구역 표식 등을 보관한다. 현재 방은 5개다.

배치를 수정할 때는 캐릭터의 실제 충돌 크기와 통행 공간을 확인한다. `tests/test_levels.py`는 방 시작과 자유 이동 동선을 검사한다.

## 05. 방 시작 시 물체 안정화

`Game.load_room`은 적과 상자를 생성한 뒤 `settle_initial_layout`으로 지지면에 놓는다. 이 준비 과정에서는 낙하 공격이나 적의 타이머를 진행하지 않는다.

`layout_errors`는 방 밖 배치와 사물·캐릭터 겹침을 검사한다. 잘못된 배치를 조기에 발견하고, 방을 열자마자 상자가 떨어져 적이 죽는 상황을 방지하기 위한 처리다.

## 06. 조작과 상태별 입력

A/D는 2D 좌우 이동, WASD는 3D·4D 이동, Space는 2D 점프다. 마우스로 조준하고 왼쪽 버튼으로 발사하며 R로 장전한다. E/Q는 상자 집기·던지기다.

2·3·4로 모드를 바꾸고, Enter는 시작·재도전·방 진행 또는 4D 위치 이동을 확정한다. 일시정지와 도움말 중에는 전투 입력을 처리하지 않는다.

## 07. 포커스 상실과 반복 입력

`App.events`는 키를 누른 상태를 집합으로 추적하고 키를 떼면 제거한다. Space는 이미 누르고 있는 상태의 반복 입력으로 다시 점프하지 않도록 처리한다.

창이 입력 포커스를 잃으면 이동 키와 발사 상태를 비운다. 다른 창으로 전환한 뒤 캐릭터가 계속 이동하거나 총을 계속 쏘는 입력 고착을 막는다.

## 08. 2D 이동과 상하 조준

2D에서는 화면의 세로 좌표를 높이로 해석하고 중력을 적용한다. 플레이어는 좌우로 이동하고 지지면 위에서 점프한다.

하체는 좌우 방향을 유지하지만 상체와 팔은 마우스 높이를 따라 움직인다. 따라서 상하 조준과 발사가 가능하다. 방향 판별과 상체 변형은 `visuals.py`에 있다.

## 09. 3D 자유 이동의 2D 구현

3D 모드도 실제 좌표와 그래픽은 2D다. 같은 화면을 바닥으로 해석하고, 화면 아래로 떨어지는 중력 없이 상하좌우로 이동한다.

대각선 입력은 정규화하므로 두 키를 눌러도 이동 속도가 더 빨라지지 않는다. 2D에서 자유 이동으로 전환하면 기존 수직 낙하 속도를 초기화한다.
