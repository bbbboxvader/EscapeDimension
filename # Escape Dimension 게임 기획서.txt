# Escape Dimension 게임 기획서

> 메모지 같은 방에서 이동·중력·시간의 규칙을 바꾸며 적을 섬멸하는 2D 액션 슈팅 게임

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 게임명 | Escape Dimension |
| 장르 | 차원 전환 액션 슈팅 |
| 개발 환경 | Python, pico2d |
| 플랫폼 | Windows PC, 키보드·마우스 |
| 그래픽 | 메모지와 손그림을 연상시키는 2D 그래픽 |
| 플레이 방식 | 싱글 플레이, 방 단위 전투 |
| 목표 | 한 건물의 방들을 통과하며 모든 적을 섬멸한다. |
| 초기 개발 규모 | 방 5개, 총기 1종, 적 2종, 상자와 보급품 |

게임에서 말하는 2D·3D·4D는 플레이 규칙을 구분하는 이름이다. 모든 화면과 물체는 2D로 구현하며, 이동 방향·중력·시간 처리의 차이로 차원이 바뀌는 느낌을 만든다. 4D는 시간을 조작하는 게임적 해석이다.

## 2. 기획 의도

같은 방이라도 적용되는 규칙이 달라지면 전투 방식이 달라진다. 플레이어는 총을 쏘는 동시에 차원을 선택하고, 상자의 위치와 적의 탄환을 활용해 위기를 해결한다.

능력 사용과 실패에는 나이라는 비용이 따른다. 나이가 들수록 과거 위치를 더 정밀하게 선택할 수 있지만 이동은 느려진다. 이를 통해 강한 능력을 언제 쓸지 판단하는 긴장감을 만든다.

## 3. 핵심 재미와 차별점

### 같은 공간을 다르게 사용하는 전투

2D에서는 좌우 이동과 낙하를, 3D에서는 상하좌우·대각선 이동을 활용한다. 차원 전환은 같은 방에서 새로운 이동 경로와 공격 수단을 만드는 행동이다.

### 사물을 이용하는 전투

3D에서 상자를 적보다 화면 위쪽으로 옮긴 뒤 2D로 전환하면, 그 위치가 높이로 해석되어 상자가 떨어진다. 적을 직접 사격하거나 상자를 던지고 떨어뜨리는 등 여러 해결 방법을 제공한다.

### 멈추고 판단하는 시간 능력

4D에서 움직임을 멈추면 적과 탄환도 멈춘다. 플레이어는 탄환 사이의 경로를 살피고 최근 위치 중 하나로 이동해 위험에서 벗어난다. 다만 사용 제한 시간은 계속 줄어들므로 빠른 판단이 필요하다.

### 정밀함과 기동력의 교환

노화는 남은 기회이면서 능력의 변화다. 나이가 많아지면 시간 이동의 선택 간격이 촘촘해지지만 이동 속도가 감소한다. 생존 경험이 쌓일수록 플레이 방식도 달라진다.

## 4. 공간과 시각 표현

방은 거의 백지에 가까운 메모지처럼 표현한다. 얇은 경계선, 단순한 문과 상자, 작은 표식으로 공간을 구성하고 벽·바닥을 강하게 구분하는 원근 표현은 줄인다.

같은 화면의 세로 좌표를 2D에서는 높이로, 3D에서는 바닥의 위치로 해석한다. 차원 전환 시 배경을 교체하지 않고 이동 안내, 색상, 그림자와 효과를 바꿔 상태를 전달한다. 사물 위치의 모호함을 전환 연출에 활용하되, 현재 모드와 충돌 경계는 알아볼 수 있게 표시한다.

| 모드 | 공간의 해석 | 주요 시각 안내 |
|---|---|---|
| 2D | 세로 방향은 높이 | 좌우 화살표, 아래 방향 중력 표시 |
| 3D | 화면 전체가 이동 가능한 바닥 | 8방향 화살표, 바닥 위치를 보여 주는 그림자 |
| 4D | 3D 이동 규칙에 시간 조작 추가 | 과거 위치 잔상, 시간축, 남은 사용 시간 |

## 5. 기본 플레이 흐름

1. 20세로 게임을 시작하고 첫 번째 방에 들어간다.
2. 적·상자·탄환의 위치를 확인한다.
3. 차원을 전환하며 이동, 사격, 투척, 낙하 공격을 사용한다.
4. 필요하면 4D로 시간을 멈추고 과거 위치로 이동한다.
5. 방의 적을 모두 처치하면 다음 방으로 진행한다.
6. 마지막 방까지 섬멸하면 클리어한다.

피격으로 사망하면 나이가 증가하고 해당 방 진입 전 상태로 재도전한다. 40세 이상이 되면 전체 게임오버이며 처음부터 다시 시작한다.

## 6. 차원별 규칙

### 2D — 평면과 중력

- A·D로 좌우 이동한다.
- 플레이어·적·상자에 화면 아래 방향의 중력이 적용된다.
- 바닥과 구조물 위에 서거나 상자를 엄폐물로 활용한다.
- 3D에서 위쪽에 배치했던 상자는 전환 후 아래로 떨어진다.

### 3D — 자유 이동

- W·A·S·D로 상하좌우 이동하고 동시 입력으로 대각선 이동한다.
- 화면 아래 방향의 낙하 중력을 적용하지 않는다.
- 상자는 바닥에 놓인 물건처럼 해당 위치를 유지한다.
- 적을 우회하거나 상자를 옮겨 다음 2D 전환을 준비한다.

### 4D — 시간 조작

- 이동 방식은 3D와 같다.
- 플레이어가 실제로 움직이지 않으면 적·탄환·물체·장전 진행이 멈춘다.
- 플레이어가 움직이면 세계의 시간이 진행된다.
- 자신의 탄환도 시간 정지의 영향을 받는다.
- 한 번의 사용은 실제 경과 시간 기준 최대 10초다. 세계가 멈춰도 제한 시간은 줄어든다.
- 최근 4초 안의 플레이어 위치를 선택해 시간 이동할 수 있다.
- 시간 이동을 실행하면 즉시 3D로 돌아온다.
- 수동 전환·시간 만료·시간 이동 등으로 4D를 종료하면 나이가 1세 증가한다.

시간 이동은 플레이어의 위치만 복원한다. 탄약, 적의 생사, 이미 증가한 나이 등은 되돌리지 않는다. 물체나 적과 겹치는 위치는 선택할 수 없도록 표시한다. 기록이 4초보다 짧으면 기록된 범위 안에서 선택한다.
